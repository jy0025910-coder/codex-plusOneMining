## 设计意图

保留沙漠峡谷、十字通道、左侧练习区、右侧排行榜、正前方矿洞与中央四个摊位。三款已认可的练习石作为风格锚点，造型不在本轮重新设计。

- 围墙：用前后错落、横向分层的大块砂岩形成连续围合，减少重复圆柱状岩块。近景立面展示目标轮廓和材质方向。
- 铺地：浅冷灰主路、中灰次级边带、深灰厚路缘。保留低频石材色差，控制细斑点，避免灰白过曝和强烈黄染。
- 体量：整体边长初步建议由约 168 扩至 210–220 studs，属于设计提案，尚未验证落地尺度。总面积增加约 56%–71%。摊棚、矿洞入口与标牌按设施分别调整，禁止将玩家和全部物件统一放大。
- 空间：扩大后仍需保持中央道路与设施的紧凑关系，练习台收紧空余边距，以台阶、岩壁前后层次和功能设施建立中景，避免单纯增加空地。
- 材质：保持卡通夸张、宽面与清晰棱角，使用克制的岩层纹理、木纹和石材明暗差；不靠高亮塑料或遍地霓虹表现精致。
