## 统一图形语言

- 玩家幻想：在明亮沙漠峡谷训练、挖矿、卖矿、升级装备。
- 已批准的视觉锚点：`力量反馈_v2/Icons/Pickaxe_B_512.png`。
- 色彩角色：深蓝黑描边；蓝钢色代表工具；琥珀橙代表木柄、皮具和奖励；矿灯青代表功能入口；紫色只少量用于重生。
- 形状：厚实、略夸张的轮廓，清晰大色块，金属与帆布区分；少纹理、少小零件。
- 光照：左上高光，2～3 档明暗；不依赖环境反射。
- 字体：数字沿用 FredokaOne / 白色黑边；中文采用清晰粗体，实际检查字体回退。
- 面板：原生 Frame / UIStroke / UIGradient 可实现的简单底板。完整概念图中的切角外形可简化成统一小圆角，先保证版式和图标一致，不能加入木雕、铆钉堆叠或复杂金框。
- 不为没有实际状态的按钮添加红点或百分比。

## 适配与验收

- 目标桌面参考 1600×900，中央角色、训练石和矿门保持可见。
- 宽度不足时改用紧凑顶栏；左右菜单折叠为入口，资源栏移出移动摇杆区域；不把整套桌面 HUD 缩成很小按钮。
- 触屏按钮可点区域至少约 48 px；保留摇杆和跳跃角落，不在它们上面放商品。
- 商品 UI 不从草稿硬编码价格；未接通购买时不能弹出真实购买流程。
- 在实际游戏内检查桌面、窄屏、横屏触屏和手柄布局；概念图和离线缩小预览不算 Studio 验证。
- 未完成：用户批准、每张独立透明 PNG、图片上传、原生 UI、功能接入、多尺寸运行检查。本轮只完成两张评审图和制作约束。
