# 收矿站资产与工程

用 Roblox Studio 打开上一级的《晶脉峡谷_收矿站.rbxlx》，按 F5 试玩。点击矿格装矿，最多携带五块。走进收矿摊前的绿色框，服务器会逐块计价、清空背包并增加金币。背包栏显示每块矿石的名称与价值。

## 资产结构

| 资产 | Studio 位置 | 复用方式 |
| --- | --- | --- |
| 峡谷小镇 | Workspace / Gem Gulch | 整个环境保留为独立 Model，AssetId 为 World.CanyonTown |
| 通用摊位 | ServerStorage / GameAssets / Buildings / MarketStall | 修改招牌、棚布与柜身颜色，替换陈列物 |
| 矿工商贩 | ServerStorage / GameAssets / Characters / ProspectorMerchant | 独立角色 Model，可摆放到其他摊位的 NpcMount |
| 自动出售框 | ServerStorage / GameAssets / Interactions / AutoSellZone | 绿色地面图案与不可碰撞的 Trigger，支持旋转、移动 |
| 柜台陈列 | ServerStorage / GameAssets / Props / OreCounterDisplay | 单块青晶矿与木托盘，可单独更换 |
| 矿石样品 | ServerStorage / GameAssets / Props / OreSamples | 独立的 Stone、Copper、MintCrystal、Amethyst、Gold |
| 完整收矿站 | ServerStorage / GameAssets / Stations / OreBuyer | 由通用摊位、NPC、出售框和陈列组合而成 |
| 当前场景实例 | Workspace / Gem Gulch / OreBuyer | 已放置的完整收矿站，编辑模式即可看到 |

所有模板都有独立的 AssetId、版本信息、明确的层级和原点。摊位的 Mounts 包含 NpcMount、DisplayMount 和 ZoneMount。各部分都是可编辑的原生 Roblox 实例。

《资产/OreBuyerKit.rbxmx》是可单独导入其他项目的模型库。放入 ServerStorage 后命名为 GameAssets。模型库中的出售框需要配合 SellZoneService 才有售卖行为。

## 程序结构

- ReplicatedStorage / Shared / OreCatalog 定义固定五格容量、稳定矿石 ID、显示名称和单价。
- ServerScriptService / Services / InventoryService 维护每位玩家独立的物品列表、金币和原子出售事务。每个槽位复制到 Player.OreInventory，客户端只负责显示。
- ServerScriptService / Services / SellZoneService 每 0.15 秒在服务器检测玩家是否位于标记为 OreSellZone 的 Trigger 中。背包为空时跳过，避免重复入账。支持多个、移动后和旋转后的出售区域，模板库中的 Trigger 不参与场景检测。
- ServerScriptService / Services / MiningService 保留原挖矿与工具升级入口，物品增减调用 InventoryService。
- ServerScriptService / Services / MerchantAssets 提供复用摊位与商贩的工厂函数。
- ServerScriptService / GameBootstrap 统一启动游戏服务。
- StarterPlayer / StarterPlayerScripts / DigController 处理挖矿输入、背包显示与本地反馈。

对应 Luau 源码位于本目录的 src，场景文件内也包含完整源码。当前场景是可编辑的作者文件。修改场景后请先保存，再同步需要保留的源码与模型模板，避免后续导入覆盖编辑。

## 创建未来的镐子店

在 Studio 命令栏使用下面的服务端代码。它会复用同一个通用摊位和 NPC，配置新的招牌与颜色。镐子的商品陈列、购买目录和购买行为可以分别添加。

```lua
local Factory = require(game.ServerScriptService.Services.MerchantAssets)
local stall = Factory.CreateStall(
    workspace["Gem Gulch"],
    "PickaxeShop",
    CFrame.new(38, -.25, 0),
    {
        Title = "镐子铺",
        Accent = Color3.fromRGB(37, 108, 140),
        Canopy = Color3.fromRGB(83, 177, 214),
    }
)
Factory.AttachMerchant(stall)
```

## 验证记录

已在 Studio 单客户端通过真实挖矿输入挖满五格，第六次输入被容量检查拦截。测试袋包含四块铜矿和一块青晶矿，共 46 金币。站在出售框外保持背包与金币不变，进入框内自动变为零矿石、46 金币。连续执行区域检测后金币保持 46。

多人并发与真实手机设备尚未验证。Output 中存在 Studio 内置 Assistant 插件加载警告与原场景资源 203785492 类型不匹配记录。

后续 NPC 的质感以 ServerStorage / GameAssets / Characters / ProspectorMerchant 为参照。这个样板直接取自场景里的 Miner。保留 R15 身体轮廓、衣料贴图中的袖部明暗和衣缝，以及身体和帽子的 Plastic 材质与零反射值。新职业可以更换衣服、颜色和配件，在同一摊位光线下对照样板。当前 ProspectorMerchant 使用原矿工的衣裤与矿灯帽，换成笑脸和伸手接矿的固定姿势。

新版单客户端验证中，测试背包在绿框外保留五种矿石。角色进入框内后，背包清空，金币从 0 增至 110，停留时余额保持 110。已验证工厂能为旋转后的镐子铺更换招牌、棚色并按挂点放置 R6 店员。


外部蛋模型、光环包、独立展示人物及特效样品已清理。角色外观基准使用正在工作的 ProspectorMerchant。出售框采用四面连续 SurfaceGui 与 UIGradient，底部浓绿、向上透明，高度 1.2 studs。七处低频星点总发射率为每秒 2.24。已在单客户端验证出售 110 金币、空背包与余额稳定。
