# Plus One Mining / 晶脉峡谷

当前核心玩法试玩保存在本地同一原型 `outputs/晶脉峡谷_三区矿洞初稿.rbxlx`，按 F5 试玩、G 打开矿工手册。玩法说明与验证记录见 `outputs/工程/资产/CoreGameplay_v1/README.md`。早期云端工程「+1矿工」（placeId `95023028297106`）仍保留此前版本。

- 点击场景增加力量与经验，并弹出第二款卡通铁镐图标。待机时右肩扛镐，进入左侧练习区每约 0.533 秒自动敲击，靠近矿墙自动采矿，破墙后按 E 拾取带价矿石。
- 五条矿道按重生次数开放，每道十层，复用矿洞外壳。六个训练区为 1、2、4、6、8、10 倍。每轮 50 级重生，上限二十次。
- 墙伤害按力量与镐倍率计算。破墙独立抽取五块矿石，允许重复。背包容量为 5，返回绿色光幕按采出品质自动出售，并点亮图鉴。镐商店、隐藏收藏与秘技可在手册中操作。
- 四面峡谷围合，十字石砖路的四个折角放置摊位；左侧霓虹练功区有三种巨型矿石与受击反馈。
- 玩家保留自己的 Roblox 形象和服装。

可编辑脚本在 `outputs/工程/src`，路径对应 Studio 的服务与容器。模型三视图、Blender 源文件、GLB 和可直接插入的 Roblox 预制件在 `outputs/工程/资产`。

`MiningAssets` 管理装备与矿石实例；`MiningService` 校验服务器玩法；`MiningMotion` 同步挥镐时刻；`MiningAnimator` 播放关节动作；`MiningFeedback` 管理点击圈、碎石和飘字。光幕继续复用 `ZoneVisuals`；`CampEnvironment` 管理峡谷环境，`RockImpact` 管理受击反馈。

当前是本地原型，进度按会话维护。试玩与复用说明见 `outputs/工程/三区矿洞初稿说明.md`。

第二款铁镐图标、Studio 导出的 UI 组件和接入说明见 `outputs/工程/资产/力量反馈_v2/README.md`。

矿工 HUD 使用已确认的独立透明图标，金币为 A 款；平面浅蓝按钮、礼包白色米字放射光、资源栏渐隐阴影与亮绿卡通钱数保持原风格。背包、金币、力量、等级与经验读取实际会话状态，菜单接入商店、矿道、重生、图鉴和秘技。Robux 力量礼包仍为界面样稿。HUD 组件记录见 `outputs/工程/资产/MiningHUD_v2/README.md`；原始图标和图片 ID 保留在 `outputs/工程/资产/MiningHUD_v1/README.md`。
